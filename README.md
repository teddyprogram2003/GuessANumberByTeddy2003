# Guess A Number 🎯

A simple **Guess A Number** game written in Python.

## 🎮 About the Game

The computer randomly chooses a number, and the player has to guess it.

After each guess, the game gives a hint to help the player:

* 📈 **Too low** — the guessed number is smaller than the secret number.
* 📉 **Too high** — the guessed number is larger than the secret number.
* 🎉 **Correct!** — the player guessed the secret number.

## 🛠️ Technologies and Tools

* **Python 3** — programming language
* **PyCharm** — development environment
* **Git** — version control
* **GitHub** — project repository

## ⚙️ How It Works

1. The computer generates a random number.
2. The player enters a guess.
3. The program compares the guess with the secret number.
4. The player receives a hint.
5. The process continues until the correct number is guessed.

## ▶️ How to Run

Make sure Python 3 is installed, then run:

```bash
python guess_a_number.py
```
